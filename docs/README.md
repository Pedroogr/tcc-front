# Documentação de continuidade

Esta pasta registra o contexto visual e operacional do frontend do TCC. Ela
serve para outra sessão ou outro agente entender o que já existe antes de
recriar telas.

## Arquivos

- [`agent-handoff.md`](agent-handoff.md): ordem de leitura, arquitetura atual e
  cuidados para alterar o frontend;
- [`current-state.md`](current-state.md): snapshot do que está implementado;
- [`design-direction.md`](design-direction.md): diagnóstico visual e direção
  proposta para o redesign.

O comportamento da API continua definido pelo repositório irmão `tcc-back`.
